# 한음→일음 변환기

한글 텍스트를 발음 기준으로 분석해서 히라가나/가타카나로 근사 변환해주는 정적 웹앱입니다.

## 주요 기능
- 실시간 한글 → 가나 변환
- 히라가나 ↔ 가타카나 토글 (기본값: 히라가나)
- 토글은 **그 시점 이후 입력한 글자에만** 적용됨 (이미 변환된 글자는 유지)
- 받침 연음(예: "문근영" → "ムングニョン")·비음화(예: "합니다" → "はむにだ") 반영
- 조사 표기 보정 옵션 (와→は, 에→へ, 오→を, 기본 꺼짐)

## 실행 방법
별도 빌드 과정 없이 `index.html` 파일 하나로 동작합니다. 브라우저로 `index.html`을 열기만 하면 됩니다.

## GitHub Pages로 배포하기
1. 저장소 Settings → Pages
2. Source를 `Deploy from a branch`로, Branch를 `main` / `/(root)`로 설정
3. 잠시 후 `https://<사용자명>.github.io/<저장소이름>/` 에서 접속 가능
